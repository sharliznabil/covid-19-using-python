# covid-19-using-python
This project is a data analysis notebook exploring COVID-19 test data using Python and libraries such as Pandas, Matplotlib, and Seaborn. It provides insights into testing results, egypt region ,  and more.

## 📊 Project Objectives

- Load and clean COVID-19 testing data.
- Analyze positive and negative test distributions.
- egypt region.
- Visualize data using graphs and plots.



Link to dataset: [Kaggle Notebook](https://www.kaggle.com/code/sharliznabil/covid-19-test/notebook)
